Getting started

Join with a pinned genesis

The address of this page is the bootstrap origin. The machine-readable manifest lives at __SPLITCHAIN_BASE__.well-known/splitchain-testnet.json. The CLI checks it and the hosted genesis against your reviewed local copy.

01 / VERIFY

Check the network

Clone the repository and verify the published genesis digest before trusting the RPC address.

02 / GET A TEST ACCOUNT

Operator enrollment

Request one account credential from the testnet operator. Keep its secret private and use a fresh nonce for each signed request.

03 / TRANSFER

Try a branch

Use the signed WebSocket endpoint to offer, accept, and commit a transfer. The private round driver advances finality.

git clone https://github.com/bokiloki/SplitChain.git
cd SplitChain
python3 -m venv .venv
. .venv/bin/activate
pip install .
scplit join-testnet --url __SPLITCHAIN_BASE__ --genesis configs/testnet-genesis.json

After enrollment, use __SPLITCHAIN_RPC__ with scplit rpc. See the step-by-step transfer guide for signed requests and operator setup.
