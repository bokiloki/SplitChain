Try SplitChain
on your device

The Android app and browser wallet connect to the same pinned public testnet. Test units are valueless and may be reset.

Android APK

Install the experimental testnet wallet on Android 8.0 or newer. It checks the published genesis and stores your private credential with Android Keystore.

Download SplitChain Testnet APK ↗

This is an installable debug APK. Check the GitHub release and build results before installing. It is not a Play Store app.

Use the browser

No installation needed. The browser wallet signs transfers in the current tab; its credential is not saved in browser storage. Use a trusted device and disconnect when finished.

Open browser wallet →

Both wallets support offer, accept and commit. A sender must have the amount plus equal temporary stake available.

Testnet only. These units have no monetary value and do not represent future mainnet coins. A debug APK can be signed with a different key on each build; a later APK may require uninstalling the old app. Back up your account credential privately before uninstalling, because the app does not export it.

Give a tester access

  1. The operator creates one account per tester, then privately gives that person its account ID and 64-character hex credential. Never publish the credential. See the operator setup and funding instructions.
  2. The tester downloads the APK or opens the browser wallet, enters the assigned credential, and shares only the public account ID.
  3. The operator funds that ID from the testnet faucet. The tester refreshes and accepts the pending offer; the operator commits it. After finality rounds, the balance becomes available.
  4. To try a transfer between testers, the sender makes an offer, the recipient accepts, and the sender commits. Refresh after each step to see its status.

Network bootstrap: __SPLITCHAIN_BASE__.well-known/splitchain-testnet.json. You can also inspect the live ledger.
